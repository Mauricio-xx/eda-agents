\begin{frame}{What this deck adds}
  \begin{itemize}
    \item How the autoresearch greedy loop applies to the
          \term{digital} flow on GF180MCU: what gets proposed, what
          gets scored, what counts as ``valid''.
    \item The \cmd{idea\_to\_optimize} chain: \cmd{idea\_loop} feeds
          \cmd{autoresearch}; one is sim-in-the-loop RTL synthesis,
          the other is greedy iteration over flow knobs.
    \item How the same loop dispatches proposals to either
          \term{Claude Code CLI} or \term{opencode CLI}.
    \item Five real blockers we hit live and the framework patches
          that unblocked them.
  \end{itemize}

  tour of the agents stack and the analog loop.}

    does that. We extend the autoresearch story with three new
    things: digital flow specifics on GF180MCU, the
    \cmd{idea\_to\_optimize} chain, and backend dispatch. Fifth
    section is a one-slide gotcha index from a live debug session;
    keep it engineering-honest.}
